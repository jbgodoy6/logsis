Back to index | Modbus function codes
Function code | Description
02 | Reads one or more read-only discrete input bits (digital ON/OFF states) from the device.
03 | Reads one or more 16‑bit holding registers.
04 | Reads one or more 16‑bit input registers.
16 | Writes values to one or more 16‑bit holding registers.
